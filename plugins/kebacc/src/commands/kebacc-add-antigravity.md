---
description: Save the Antigravity login you are on into the pool
allowed-tools: Bash(~/.claude-tools/kebacc:*), Bash(~/.claude-tools/kebacc.exe:*)
---

Run `~/.claude-tools/kebacc`, or `~/.claude-tools/kebacc.exe` on Windows:

```
~/.claude-tools/kebacc add -Provider antigravity
```

Report the account it saved. The address comes from Google, so it is only worth passing `-Email` if it asks for one.
