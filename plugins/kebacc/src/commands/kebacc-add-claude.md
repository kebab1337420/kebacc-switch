---
description: Save the Claude Code login you are on into the pool
allowed-tools: Bash(~/.claude-tools/kebacc:*), Bash(~/.claude-tools/kebacc.exe:*)
---

Run `~/.claude-tools/kebacc`, or `~/.claude-tools/kebacc.exe` on Windows:

```
~/.claude-tools/kebacc add -Provider claude
```

Report the account it saved. If it says you are not logged in, say so and stop.
