---
description: Forget a saved Antigravity account
allowed-tools: Bash(~/.claude-tools/kebacc:*), Bash(~/.claude-tools/kebacc.exe:*)
---

Run `~/.claude-tools/kebacc`, or `~/.claude-tools/kebacc.exe` on Windows:

```
~/.claude-tools/kebacc remove -Provider antigravity -Email <email> -Yes
```

Confirm with the user which account before running this: it is not reversible without logging in again. The live session is untouched.
