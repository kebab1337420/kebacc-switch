---
description: Save the Antigravity login you are on into the pool
allowed-tools: Bash(~/.claude-tools/kebacc-antigravity:*), Bash(~/.claude-tools/kebacc-antigravity.exe:*)
---

Run `~/.claude-tools/kebacc-antigravity`, or `~/.claude-tools/kebacc-antigravity.exe` on Windows:

```
~/.claude-tools/kebacc-antigravity add -Provider antigravity
```

Report the account it saved. The address comes from Google, so it is only worth passing `-Email` if it asks for one.
